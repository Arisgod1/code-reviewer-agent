## 初始化
```bash
mkdir code-reviewer-agent
cd code-reviewer-agent
go mod init github.com/yourname/code-reviewer-agent
```
#### 安装 cobra
```bash
go get github.com/spf13/cobra@latest
```
#### 创建目录
```bash
mkdir -p cmd/cli internal/{types,tools,report} testdata
touch cmd/cli/main.go
touch internal/types/types.go
touch internal/tools/parse_diff.go
touch internal/tools/scan_rules.go
touch internal/tools/format_report.go
touch testdata/sample.patch
```
